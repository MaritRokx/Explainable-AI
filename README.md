This project uses the UCI Adult Census Income dataset to predict whether an 
individual earns more than $50K per year. Beyond just making predictions, focusing on model explainability and fairness.

How to Run:
- Open in Colab: You can run this project directly in your browser by clicking the badge below.

- Dataset: The code downloads the adult.data and adult.test files.

- Requirements: If running locally, install the dependencies.
